# Security Policy

## Supported Versions

Only the current release line receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report vulnerabilities privately instead of opening a public issue.
Include the affected `cru` version, the recipe (sanitised of any secrets),
and a minimal reproduction.

Vulnerabilities with a demonstrated, reproducible impact are acknowledged
and, where possible, fixed in the next release. Do not log secrets or
credential material in issue reports, recipes, or build logs.
